A download manager for one-click hosters that lives on your NAS.

Click'n'Load and DLC containers like JDownloader, but headless from the start: one container or one Go binary, a web UI instead of a desktop app, and a browser extension that sends links from your PC to the server.

  • MIT
  • Go, no CGO
  • amd64 + arm64
  • no telemetry
  • single bbolt file

Docker Compose, no checkout needed

$ mkdir hopper && cd hopper
$ curl -fsSLO https://raw.githubusercontent.com/simuuh/hopper-downloader/main/docker-compose.yml
$ curl -fsSLo .env https://raw.githubusercontent.com/simuuh/hopper-downloader/main/.env.example
$ docker compose up -d
$ docker compose logs hopperd   # prints the admin password once

Then open http://<host>:9667. Settings go into .env; update with docker compose pull && docker compose up -d. Binaries for Linux, macOS and Windows are on the release page.

What it does

Links inClick'n'Load 2 (filecrypt, hide.cx, …), .dlc and .txt import, pasted text, sharing from a phone, REST API
HostersReal-Debrid, AllDebrid, Debrid-Link and Premiumize with a priority order: if the first can't serve a link, the next one takes it. Native plugins for Rapidgator, 1fichier, Katfile and DDownload.
AccountsSeveral per hoster, rotated automatically when one runs out of traffic. Credentials encrypted at rest (AES-256-GCM).
DownloadsParallel chunks, resumable after a restart. A resumed file must still be the same version on the server (ETag / If-Range), and a file is only marked done when every byte arrived.
PackagesArchive parts grouped per release; later parts merge into the existing package; duplicates and mirrors are skipped.
ExtractionRAR (multi-part, password list), ZIP, tar. Automatic once every part is on disk, or on request.
NotificationsWebhook or ntfy when a package is finished.
Runs onDocker (amd64, arm64) or a single binary for Linux, macOS, Windows. Web UI embedded, CLI client hopperctl included.

How links get from the browser to the NAS

Click'n'Load buttons on link-protector sites always talk to 127.0.0.1:9666, the PC you're sitting at. The extension catches that call inside the page and forwards it to hopperd on the server, so nothing has to run on your PC.

Links from a page arrive paused. Any website could send links to that port; downloads start only when you start them in the web UI.

.dlc files downloaded in the browser are imported directly. Details in REMOTE_CLICKNLOAD.md.

Parts download in order and are extracted once the last one is on disk. If something stays packed, hopperd's log says why.

What Hopper deliberately doesn't do

  • No captcha-solving services, no router reconnects. Use a debrid account instead of waiting out free-tier limits.
  • No plugins for hundreds of hosters and video sites. A debrid account covers most hosters; a few native plugins cover the rest.
  • No multiple users. One admin, one queue.
  • No library management. Sorting finished downloads into movies and series is Folder Mover's job.
  • No phoning home. The only fixed outbound call is the DLC key exchange with service.jdownloader.org when you import a .dlc.

If you need those things, JDownloader is the better tool.
